## 🚀 Proyek Utama (Hero Projects)

### 1. Sistem Evaluasi & Klastering Kinerja Kurir Logistik
Sistem cerdas untuk mengelompokkan dan mengevaluasi performa kurir (studi kasus: GoTo Logistik) guna mengoptimalkan manajemen SDM dan distribusi.

*   **Tujuan Bisnis:** Memetakan produktivitas kurir berdasarkan data historis pengiriman.
*   **Metodologi:** 
    *   **K-Means:** Mengklaster kurir berdasarkan kecepatan dan tingkat keberhasilan pengiriman.
    *   **DBI (Davies-Bouldin Index):** Mengevaluasi validitas jumlah klaster agar optimal.
    *   **TOPSIS:** Memberikan *ranking* absolut untuk performa kurir terbaik.
*   **Tech Stack:** Laravel (PHP), Blade (Frontend), MySQL.

### 2. Enterprise Point of Sale (POS) & Manajemen Transaksi
Aplikasi kasir modern yang dirancang untuk kecepatan transaksi dan pencatatan inventaris secara *real-time*.

*   **Fitur Utama:** Manajemen kategori produk, sistem *checkout* dinamis, dan pelacakan riwayat transaksi harian.
*   **Arsitektur:** Menggunakan pendekatan SPA (Single Page Application) tanpa perlu membuat API terpisah.
*   **Tech Stack:** Laravel 12 (Backend), Vue 3 (Frontend), Inertia.js (Bridge), Tailwind CSS (Styling).

### 3. Warehouse Management System (WMS) dengan Barcode Support
Sistem inventaris gudang kompleks untuk mengelola arus keluar-masuk barang secara presisi dan mengurangi risiko kehilangan aset.

*   **Fitur Utama:** *Tracking* barang masuk/keluar, *generate* laporan otomatis (PDF/Excel), integrasi *barcode scanner* untuk setiap unit barang.
*   **Tujuan Bisnis:** Digitalisasi total operasi gudang konvensional.
*   **Tech Stack:** Django (Python), Django Templates, SQLite/PostgreSQL.

### 4. DSS Bantuan Pangan Non-Tunai (BPNT) dengan AHP & SAW
Implementasi model matematika menggunakan *spreadsheet* untuk menentukan target demografis paling layak menerima bantuan sosial, berdasarkan *case study* masyarakat miskin.

*   **Metodologi:**
    *   **AHP (Analytical Hierarchy Process):** Menentukan bobot kriteria kelayakan (penghasilan, tanggungan, kondisi rumah).
    *   **SAW (Simple Additive Weighting):** Menghitung skor akhir untuk rekomendasi penerima.
*   **Alat Utama:** Microsoft Excel (Pemodelan Data Tingkat Lanjut).
